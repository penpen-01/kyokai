# イラストの道具

## 依頼文を作る（Gemini 用）
`python3 tools/art/requests.py カード指定.py 出力.html` → コピーボタン付きのページと `出力-order.json`（並び）ができる。
カード指定の書き方は `example_cards.py`（第2弾-3 幻想の描き直し。うまくいった実例）。

### うまくいくやり方（2026-11-10 にオーナーと確認）
- **1枚ずつ貼る**。何枚分もまとめて「次」で進めると、後のカードほど指示が抜け、前の絵をまねする（依頼文が絵に描き込まれることもある）
- **1つの会話は4〜5枚まで**。会話ごとに新しくする。1枚目だけ画風の見本 art-style-ref.png を添付し共通ルールを送る。2枚目からは「最初に添付した画像の画風で…前の絵の背景・構図は使わない」で始まる短い文
- **似た人物は同じ会話に入れない**（例：狐の女性3人は別々の会話へ）
- **キャラクターのカードは主役を中央に大きく**。相手や脇役は小さく。SR以上でも「画面全体の場面」にしない（魔法カードに見える）
- **場所と時間帯をカードごとに書く**。世界の雰囲気に「夜の森」などと書くと全部同じ背景になる
- 「画面の下は地面だけ」と書くと毎回同じ草・木の根で埋まるので「ただの地面や影でよい。毎回同じ草や根を描かない」と書く
- **同じ人物を別のカードで描くときは、絵を添付しない**。見た目（髪・服・武器）を文字で書き、ポーズと構図をはっきり指定する（燕返しで成功）
- 相手役にほかの世界の存在を入れるのは良い。ただし毎回同じ見た目にならないよう、人物を具体的に書く（「金と青の騎士」ばかりになった）
- 実在の作品のキャラに似たら入れない（木霊の礫がコダマに似た）。透かし入り・有料の素材は使わない
- 文字だけ返ってきたら「画像を生成して」とだけ返す

## 絵を入れる
`python3 tools/art/put.py カードID=画像.png ...` または `python3 tools/art/put.py --order 出力-order.json 会話① 画像1 画像2 ...`
入れたら sw.js の CACHE を上げてコミット・push（push の前に git fetch → rebase）。
