# 境界の塔・分身戦（β・2026-11-24）

## 境界の塔（js/tower.js）
- 全30階。毎週月曜0時（日本時間）に1階からやり直し。負けても同じ階に何度でも挑める。デッキは階ごとに替えてよい（サンプルデッキは不可）
- 各階の相手と試練は「週の番号＋階」から自動で決まる（誰がいつ見ても同じ塔）。**毎週の作業はない**
- 階ごとの強さ（TOWER_TIERS）
  - 1〜9階：中級のデッキ・中級の考え方。試練は5階から1つ
  - 10階：門番（開放戦のデッキ・上級の考え方）
  - 11〜19階：上級のデッキ。17階から試練2つ
  - 20階：門番（ネザルのデッキ・体力25）
  - 21〜29階：超級のデッキ。27階から試練3つ
  - 30階：門番（黄泉丸のデッキ・体力30）
- 試練（TOWER_MODS）：堅牢（相手の体力+5）／鉄壁（+10、16階から）／先手の魔力（相手は最初からエナジー+1）／手負い（自分の体力-5）／天門の番兵・精霊の群れ・量産ライン・竜の巣・天使の守り（相手の場に最初からトークン。1つの階に1つまで）
- 調整は TOWER_MODS と TOWER_TIERS を変えるだけ。順位：tower/<月曜の日付>/<uid> = { n, f, at }

## 分身戦（js/ghost.js）
- 自分のデッキを1つ「分身」として置く（ghost/<uid>）。友達の分身を選んで戦う（相手は上級の考え方）
- 結果は ghostLog/<分身の持ち主>/<自動> = { by, n, res, at }（res は挑んだ側から見た勝ち負け）。3ターンより前に終わった対戦は残さない
- 今週の「倒した数」（同じ相手は1日1回まで数える）と「守った数」で順位

## 報酬の案（β のあいだは無し。正式にするときに決める）
### 塔（毎週）
| 到達 | 報酬 |
|---|---|
| 5階 | 300G |
| 10階 | 魔石100・パック券1 |
| 15階 | 800G |
| 20階 | 魔石200・パック券1 |
| 25階 | 1500G |
| 30階 | 魔石400・パック券2 |
- 1週で全部取ると 2600G・魔石700・パック券4。選定戦の7勝（10000G…）より軽く、毎週もらえる分を小さめに
- 30階に**初めて**登ったときだけ：限定の枠と称号「塔を極めし者」
- 週の1位：称号「今週の塔の主」（次の週の1位が決まるまで）

### 分身戦
- 挑む側：分身に勝つと魔石30（同じ相手は1日1回、1日5人まで → 1日最大150）
- 守る側：自分の分身が守るたびに1点。週の終わりに 1点＝魔石20（週300まで）。ホームで受け取る
- 週の「倒した数」「守った数」の1位に称号
- わざと負ける対策：守った点は「同じ挑戦者からは1日1点まで」にする
