# 見た目の作り直しの計画（2026-11-20 オーナーと決めた。作るのは 11-21 から）

オーナーの評価：「一人で遊ぶ」「オンライン」「CPU戦」の画面、試合開始・じゃんけん・先攻後攻・勝敗の演出、連勝の炎が、商業ゲームに比べてダサい。
Gemini の絵は、届いたら背景を抜いて ui/ に入れる（緑 #00FF00、緑の絵はマゼンタ #FF00FF）。

## 1. メニュー画面（一人で遊ぶ・オンライン・CPU戦）
今の問題
- どのタイルも同じ「暗い四角＋左の色の線＋薄い絵」で、絵が見えない（不透明度が低い）
- 背景が無地の紺。見出しが文字だけ
- 一人で遊ぶ・オンラインは下半分が空いている。CPU戦は左下のデッキボタンが超級に重なる
直し方
- 画面ごとの背景の絵（一人で遊ぶ＝夜の訓練場、オンライン＝闘技場）を敷く
- 見出しは金の飾り板（絵）の上に文字
- タイルは金の飾り枠（絵）で囲み、絵を明るく大きく。文字の側だけ暗くぼかす
- 一人で遊ぶ：CPU戦を大きく（画面の4割）、選定戦を中、練習・チュートリアル・開放戦を下に3つ横並び（1画面に収める）。開放戦は全部開けたら小さい札だけ
- オンライン：アリーナを大きく（扉の絵＋開始までの残り時間＋前回の1位）、友達と対戦は英雄王の絵を使った横長タイル1つ＋「作る／入る」の2つのボタン
- CPU戦：難しさの星は宝石の絵、報酬はコインの絵の札、連勝は小さいメダル。デッキボタンが重ならないよう下に余白

## 2. 試合開始（VS）
今：代表カードが斜めに飛んできてぶつかる・後ろに絵が透ける。迫力がない
直し方（2.5秒・タップで飛ばせる）
1. 暗転して、画面の真ん中に横一線の光の裂け目（境界）が走る
2. 上から相手、下から自分の帯がすべり込む。帯いっぱいに代表カードの絵（顔が見えるように大きく切り抜き）、名前・称号・デッキ名
3. 真ん中に VS の紋章（絵）が叩きつけられる → 衝撃の輪・画面の揺れ・火花
4. 帯が上下に割れて退場 →「BATTLE START」の文字（字はこちらのフォント、後ろの飾りは絵）

## 3. じゃんけん
今：楕円のボタンに小手の絵。普通のボタンに見える
直し方：3枚のカード（グー・チョキ・パーの絵）を扇に並べ、押すと選んだ1枚が浮き上がって他は消える。相手のカードは裏から表へめくれる。あいこは両方が砕けて配り直し

## 4. 先攻・後攻
今：丸い札に文字
直し方：先攻＝金の剣の紋章、後攻＝銀の盾と境界の欠片の紋章（絵）。紋章が叩きつけられ、光の輪。文字はこちらで重ねる

## 5. 勝敗と報酬
今：VICTORY の文字＋箱＋炎の列。炎は33個並ぶとくどい
直し方
- 勝ち：相手の顔がひび割れて砕ける → 画面が白く光る → 金の月桂冠の紋章（絵）の上に VICTORY が打ち込まれる
- 負け：自分の紋章が灰色に砕ける。DEFEAT は暗い青で静かに
- 報酬：コインが何枚も飛んで所持金に吸い込まれ、数字が数え上がる
- 連勝：炎の列をやめて、炎をまとったメダル（絵）に連勝数を大きく。ボーナス%は帯で。10・20・30連勝で色が変わる
- ボタン：「もう一度」を大きく。ほかの4つは下のメニューと同じ紋章のアイコン
