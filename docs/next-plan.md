### アリーナ（β、js/arena.js）
- 決まった時間だけ開くランダム対戦。毎日21〜22時（JST）＋オーナーが言った時間（game-data.json の arena.extra に足す）
- ルールは曜日で替わる：days[日〜土] = std / std / sen / set1 / std / sen / set1（通常戦・選定戦・第1弾限定）
- 点：勝ち3・負け1・引き分け1（arena/r/<回>/<uid>）。お互い3ターン前の降参・切断は0点、同じ相手は1回の開催で2戦まで、直前の相手とは20秒組まない
- 報酬（ARENA.rewards、11-20〜）：参加賞パック券1、1位1000G＋券3・2位500G＋券2・3位券1。回の1時間後にホームで受け取り。「これまでの結果」で過去8回のランキング
- 開いている間はホームの飾り棚が扉（ui/arena-door.webp＝扉、ui/arena-door-frame.webp＝外枠）に替わり、左右にかがり火（ui/arena-torch.webp、右は反転）。タップできしむ音→扉が奥へ開く→アリーナ画面。ホームを開いたままでも30秒ごとに開始・終了を見て入れ替える
- 11-19 に直したこと：本物の Firebase でマッチしない（transaction の初回 null）・アリーナで対戦すると名前が「見習いプレイヤー」に上書きされる・部屋を作った人の降参が相手に伝わらない・相手の接続が60秒切れたら勝ち
- 運営アカウントはいつでも「テスト」の回に入れる。同じブラウザのタブ2つは同じ uid なので自分同士ではマッチしない（試すときは別のブラウザか別の端末）
