## 新しいモード（評価）
- 世界限定：易。デッキの条件を1つ足すだけ。持っているカードが少ないと組めないので、決まったデッキかピック形式と組み合わせる
- 隠しボス：易〜中。上級に挑むと低確率で乱入。強さは有利な条件（体力・エナジー・最初から場にキャラ・専用カード）で作る（CPU をこれ以上賢くするのは難しい）
  - 運任せ＋ボス限定のレジェンドは反対 → 天井（上級で N 勝すると必ず出る）か、挑み直し（一度出たら一定時間・一定回数は再挑戦できる）を付ける
  - 確定レアチケット＝新しい道具（例：SR以上確定のパック券）。ボス限定レジェンド＝カードに「パックに入れない」印（ショップの交換からも自動で外れる）
- チュートリアル：中。決まったデッキ・決まった順の山札＋状況に合わせた案内。作るべき
- ピック形式：中。まず「各自が別々に選ぶ」形。同じ山から交互に取り合う形は、通信の手間が大きい
- ストーリー：仕組みは中、中身（文章・デッキ・絵）は大。ステージをカード工房で足せる形にして、少しずつ増やす
- 共通の土台：「この対戦は、このデッキ同士・このルール・この報酬」を決めておける仕組み
- 作る順番の案：土台＋世界限定 → ボス → チュートリアル → ピック → ストーリー

## Claude の答え
- 第1弾に足すカード：機械のレア3〜4種（コスト5〜6中心）だけ。機械は37種・レア8種・コスト5〜6が5種しかない
- 値段：1枚あたり20G→50G（2.5倍）。全部を3枚ずつそろえるのに必要な量（シミュレーターの中央値）
  - 第1弾：約640パック・64,000G
  - 新パック1つ（60種・4枚）：約225パック・45,000G＝上級で約150勝
  - 新パック3つで上級約450勝（今の約2倍）→ 報酬の G を上げる案
- 種類数：おすすめは45種前後（C18 R13 SR8 UR4 L2）。60種なら C24 R18 SR10 UR6 L2
- 名前：コモンは一般名、レアは半分、SR以上は全部に名前。神話＝称号＋名前、幻想＝童話・伝承風、機械＝役割＋コードネーム
- 公開の条件：連勝は反対。例「その世界のデッキで中級に3勝」。ボスは開く条件ではなく報酬の側へ
- リセット：引き継ぎコードは残し、カード・G・魔石を消す
