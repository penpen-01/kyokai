# これまでの決めごとと理由（〜2026-11-01）

最初のチャットで決めたことの記録。新しいチャットで「なぜこうなっているか」を知るために読む。

## ゲームの基本

- 1対1、デッキ構築（30枚・同名3枚まで。カードごとの上限 `limit` もある）、プレイヤー体力20、エナジー上限10、場は4体まで
- 神話（金）・幻想（緑）・機械（青）の3つの世界。1試合5〜15分が目標
- 開始時：じゃんけん → 勝った人が先攻／後攻を選ぶ → 初期手札（今は5枚）→ 1回だけ全部引き直せる（マリガン）
- 先攻は最初のターンに引かない。後攻は「境界の欠片」を持つ
- 2026-10-31 のルール変更：守護がいなければ相手キャラがいても本体を攻撃できる。直撃＝守護を無視（名前は「直撃」のまま、とオーナーが決定）
- 理由：旧ルールだとランプが強すぎ、速攻が勝てなかった（docs/balance-notes.md）

## 経済・アカウント

- ログインなし。16文字の引き継ぎコードでアカウントを識別（Firebase の `seasons/<シーズン>/accounts/<コード>`）
- 勝つとG、Gでパック（5枚・最後の1枚はレア以上）。負けは0G。ダブりは所持数に加算
- シーズン名を変えると全員リセット（正式版のときに使う）
- サンプルデッキ：ベータ中は所持に関係なく全カードで組める（全カード3枚まで）
- シリアルコード：カード工房で作る。公開データにはハッシュだけ。1アカウント1回
- デッキは通常・サンプルそれぞれ10個まで（`DECK_MAX`）
- ご意見フォーム：`feedback/<シーズン>` に書き込み専用。オーナーは Firebase の画面で読む
- 正直な弱点：データは各端末が書き込むので、詳しい人ならズルできる（友達内の前提）

## 見た目・演出

- 起動画面（3つの世界の斜めの帯）→ ホーム（対戦・デッキ・パック・カード一覧・ご意見、歯車の中にルール・アカウント・音・シリアル）
- カード枠はコード（CSS）で描く。**画像AIに枠を描かせない**（透明にできない・小さいと潰れる・30種類の形をそろえられない）
- キャラ：全面イラスト・丸いコスト・剣形の攻撃・盾形の体力。魔法：アーチ窓・ひし形のコスト・巻物の帯
- レア度の枠：コモン（くすんだ世界の色）・レア銀・SR金・UR太い金と光・レジェンド虹。コモンをくすませたのは、神話の色が金に近く SR と紛らわしかったため
- 手札は扇形・コスト順・使えないカードは色あせ（半透明にしない。重なったカードが透けて読めなくなるため）
- 図鑑・デッキ編成では未所持カードのイラストを隠す（サンプルデッキでは見せる）。起動画面の背景だけは宣伝として見せている
- 音は Web Audio で合成。iPhone で「再生中」表示が出ないよう ambient が基本、「マナーモード中も鳴らす」はオプション

## イラスト

- Gemini（オーナーが課金している Pro）で生成。依頼文は docs/art-list.html（セットごとにコピーできるページ）
- 失敗から学んだこと
  - 見本画像は「画風の見本だけ」と明記しないと、人物ごと写される
  - 似た役割のキャラは、性別・年齢・髪型・色・ポーズ・場所まで指定しないとかぶる
  - 機械の世界を「全部青」と指定したら全カードが同じロボットになった → カードごとに色とシルエットを指定
  - 背景は毎回別の場所と明記しないと、同じ森・同じ構図が続く
  - 既存作品に似たもの（例：機神オメガがガンダム風になった）は必ず描き直す。正式公開で問題になるため
- 描き直しの候補（未対応）：鋼鉄の番兵と再起動プロトコル、召喚の角笛と冥府の契約、天馬の騎士の槍・不死鳥の騎士の剣・森羅の大精霊の足
- 正式公開時は「イラストの一部はAI生成」と書くのを推奨

## 連勝ボーナス（2026-11-01）

- 1勝目は通常の報酬、2連勝目から+10%ずつ、最大+50%。強さごとに別々に数える
- 途中でやめても連勝が途切れる（負けそうになったらやめて連勝を守る、を防ぐため）。引き分けも途切れる
- 対人戦には付けない（友達同士でわざと負けて稼ぐのを防ぐため）
