# 第3弾の構想メモ（2026-11-24〜。オーナーと相談中。決まったら書き換える）

## オーナーの考え（11-24 時点）
- パックは1つ（3つの世界が混ざって入る）。1パック5枚。値段は1弾と同じか2弾より高いか（未定）
- 枚数は1弾（134枚）と同じかそれ以下。世界ごとの種類はほぼ均等
- コンセプト未定。案：一部のカードで「墓地を肥やす→墓地から蘇生」（低コストで山札から墓地へ送る・中コストで高コストを蘇生）
- 強いカードへの対策は少しだけ。対策しすぎると連鎖になるので、無理なら強いカードを規制する（例：隠密を低コストで倒すカードは作らない）
- 規制カードの案：場にいると、相手のキャラは出たターンに攻撃できない（速攻・突進を止める。ゴーゴー量産機対策）
- 店員に負けない個性のキャラ（スタンプにできる）。個性を被らせない（水の生き物・動物ロボ・ミュータント・バイオなど解釈を広げる）
- スマホならではの効果（他のゲームのまねにしない）：盤面・体力を隠す／1ターンだけ CPU が操作／配置の入れ替え／思考時間を短くする（対人専用）／手札にある間は A・B・C のどれか（出すまで決まらない）／相手には 1/1 に見える 10/10 など
- パック開放戦のルールも決める

## 決まったこと（11-24 04:05 オーナー）
- 各世界33枚・合計99枚。1パック5枚。値段は高めにしたい（交換所との兼ね合いで決める）
- サブテーマ：「海賊・海の生き物」と「墓地からの復活・アンデッド」
- スマホならではの効果は3つ：偽装（相手には弱く見える）・ABC（出すまで中身が決まらない）・体力を隠す
- 新しい効果：次に受けるダメージを1ターンに1回まで無効（効果ダメージで削るデッキ対策）
- 開放戦：相手は3弾のカードを使う。こちらに縛りを付ける（高レアの枚数制限など、方法は相談中）
- コンセプト「歪む境界」は仮採用。パックの名前は別に考える
- 却下：時刻で変わる・育つ相棒・山札で育つ卵・目隠し・巻き戻し（環境や時刻で変わるのはよくない）

## 決まったこと（11-24 04:35 オーナー）

- カードの分け方：昼の海（明るい海。イルカ・鳥・クラゲ・港町の商人など。機械や創作の生き物でもよい）／夜の海（夜のクラゲ・深海の生物・海賊・宝箱など）／亡霊船（アンデッド・墓地から復活）／通常（海に限らない）
- 開放戦：2弾のカードだけ＋レア度の枚数の上限（最初はレジェンド1・UR2・SR6。3弾の CPU デッキを作ってから検証ラボで決める）

## オーナーの意見（11-24 11:27）
- 開封の証のような制度で解決するのはわかるが、交換所を増やしたくない → 別の方法を考える
- たたき台：低コストが多すぎ・レア度とコストを結びつけすぎ・人気が出そうなキャラ（特にレジェンド・UR）に名前がない・低レアにも個性を
- 偽装はキャラ自体に付けるとコストでばれる → 呪文や効果で手札のキャラに付けるのが面白い。偽装は機械っぽい
- 結界は「出たとき、プレイヤーに1回無効を付ける」
- 同じ弾に同じ生き物の機械版を入れない（次の弾からなら物語になるのでよい）
- タマモ・亜空間の対策を考える
→ 第2版のたたき台：docs/set3-slots.md

## オーナーの意見（11-24 12:17）
- 交換所：「その弾を10パック開けると交換所に並ぶ」でもいいが、そのあと1弾のパックしか引かれないかも → そのパックだけの「レジェンドの上のレア度」か「イラスト違い」を低い確率で入れる、または限定スキンを封入。カードを揃えたあとも引く理由ができる
- たたき台：既存と似た名前がある／レジェンドを低・中コストにも／限定的な対策は強くしてよい（亜空間ブレイクなど）
- 亡霊船：死の宣告持ちが多く、死ぬけど蘇る。その分少しだけ基礎の数値が高い。蘇生は選択式（4コストの呪文で6コストくらいまで）。既存の冥府からの帰還はランダム。手札のキャラを捨てて発動・場のキャラを破壊して発動のカードで蘇生を助ける
- どこかの高レアに、呪文を踏み倒す・呪文のコストを下げるキャラ（呪文で組めるデッキ用。コンセプトではない）
- ある程度決まったら、世界別コスト順のリスト（数値・能力・イラストも仮で）を作る
→ 第3版：docs/set3-slots.md

## 決まったこと（11-24 12:46 オーナー）
- タマモ対策：4コストくらいで「場の元々のコストが一番高いキャラを破壊」（自分も巻き込まれる）
- パック限定パラレル：採用。確率はもっと低くてよい（全部揃えさせなくてよい）
- 蘇生は【死の宣告】を持つキャラだけを戻せる（インフレしないように）。死の宣告を持つ亡霊船の仲間を増やしてよい
