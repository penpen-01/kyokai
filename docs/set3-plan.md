## オーナーの考え（11-24 時点）
- パックは1つ（3つの世界が混ざって入る）。1パック5枚。値段は1弾と同じか2弾より高いか（未定）
- 枚数は1弾（134枚）と同じかそれ以下。世界ごとの種類はほぼ均等
- コンセプト未定。案：一部のカードで「墓地を肥やす→墓地から蘇生」（低コストで山札から墓地へ送る・中コストで高コストを蘇生）
- 強いカードへの対策は少しだけ。対策しすぎると連鎖になるので、無理なら強いカードを規制する（例：隠密を低コストで倒すカードは作らない）
- 規制カードの案：場にいると、相手のキャラは出たターンに攻撃できない（速攻・突進を止める。ゴーゴー量産機対策）
- 店員に負けない個性のキャラ（スタンプにできる）。個性を被らせない（水の生き物・動物ロボ・ミュータント・バイオなど解釈を広げる）
- スマホならではの効果（他のゲームのまねにしない）：盤面・体力を隠す／1ターンだけ CPU が操作／配置の入れ替え／思考時間を短くする（対人専用）／手札にある間は A・B・C のどれか（出すまで決まらない）／相手には 1/1 に見える 10/10 など
- パック開放戦のルールも決める
