# 新しい能力・効果の実装計画（2026-11-02 オーナーと決定）

## なぜ大量に足すのか（パックの計画）

- **今あるパック**＝導入用。世界（種族）に関係なく、分かりやすい効果で始めやすいパック
- **次のパック**＝**正式リリースと同時に3種類を出す**。神話・幻想・機械がそれぞれテーマで、そのパックからは基本その世界のカードしか出ない。世界ごとのシナジーを足していく
- そのための能力・効果を先に作っておく。必要なら新カードを作ったり、既存カードに新しい能力を付けたりしてよい（オーナー了承済み。ただし数値の調整はオーナーが主導）

## 今すぐ実装する（オーナー決定）

### 発動するタイミング
- 倒されたとき
- 自分のターンの始め／終わり
- 攻撃したとき
- 敵キャラを倒したとき
- ダメージを受けて生き残ったとき
- ほかの味方が出たとき／倒されたとき
- 自分が魔法を使ったとき（スペルバースト）
- 相手プレイヤーにダメージを与えたとき
- カードを引いたとき
- 自分の体力が回復したとき
- 亜空間から戻ったとき

### 効果
- トークンを場に出す
- トークンを手札に加える（機械の「残骸」＝倒されたとき＋パーツのトークン魔法を手札に）
- 能力を与える（例：味方の機械すべてに装甲1。オーバークロック＝体力を払って2回攻撃を与える、もこれで作る）
- 手札に戻す
- 相手の山札に混ぜる
- 奪う
- 沈黙（効果と能力をすべて消す）。相手キャラ1体・相手キャラ全体・自分のキャラ1体（不動や死の宣告を消す）の3種類
- 変身（1/1にする）
- 復活（この対戦で破壊された自分のキャラを出す）
- 攻撃力と体力の入れ替え
- 山札から種類を指定して手札に加える

### 能力（キーワード）
- 隠密（攻撃するまで攻撃の対象にされない）
- 2回攻撃
- 聖盾（最初に受けるダメージを1回だけ0にする）
- 毒（ダメージを与えたキャラを破壊する）
- 吸収（与えたダメージの分、自分の体力を回復する）
- 呪文耐性（相手の魔法・効果の対象に選ばれない。全体には当たる）
- 不動（攻撃できない）
- 再生（自分のターンの終わりに体力が全回復）
- 死の宣告（旧名：寿命。次の自分のターンの終わりに破壊される）

### 条件付き（使ったとき・発動したときに1回だけ判定）
- 自分の体力がN以下
- 場に特定の世界のキャラがN体以上
- このターン、すでにカードを使った（コンボ）
- 手札が0枚
- 手札がN枚以上
- 最大エナジーがN以上

## 細かい決まり（Claude が決めて作る。作ったあとに説明し、気に入らなければ変える）
- 奪ったキャラは、そのターンは攻撃できない。自分の場がいっぱいなら奪えない（効果なし）
- トークンはデッキに入らず、パックからも出ない。工房で「トークン」の印を付けたカードとして作る
- 聖盾は1回で消える

## あとで実装する（いったん放置）
- 常に効き続ける系：オーラ、信仰（条件を満たす間だけ強い）、「手札5枚以上なら直撃」など
- 手札のカードのコスト変更（魔力共鳴の手札部分、手札の魔法すべて−1、相手のコスト＋1）
- コピー・複製（ほかのキャラと同じになる）・合体
- 数を数えて強さが変わる効果（手札の機械の枚数分ダメージ など）
- 連鎖（エコー）
- 配置条件（隣のキャラを強化）

## 実装しない（オーナー決定）
- 前借り（次のターンのエナジーが減る）
- 発見（3択）・占術・追加払い（キッカー）など、プレイ中に選ぶもの
- 手札から捨てられたとき
- 毎ターン1枚しか使えない
- ハイランダー
- 無敵（1ターン）

## 進み具合
- 段階1「発動するタイミング」：実装済み（2026-11-02 昼、`kakunin` でオーナーの確認待ち）。効果に `when` を持たせる（なし＝登場時）。発動は `S.q` に積んで `cleanup()` で順に処理（倒れたキャラを先に外す・60回で打ち切り）。登場時以外の対象はランダム。補助として「このキャラ」の効果（攻撃力＋N・＋N/＋N・もう一度攻撃できる）を追加。破壊されたキャラは `p.grave` に記録（復活用）。場のカードには「効」の印

- 段階2「トークンと効果」：実装済み（2026-11-02 昼、`kakunin` で確認待ち）。カードに `token`（limit は 0 に固定）。効果に追加の設定 `card`（トークン）・`kw`（与える能力。armor は n が値）・`world`・`ctype`（`normEffect` で整える）。キャラに `u.kws`（与えられた能力）・`u.armorPlus`・`u.silenced`。能力の判定は必ず `kw(u, k)` / `armorOf(u)` を通す。全体強化（攻撃力・＋N/＋N）にも世界の絞り込みを追加

- 段階3「能力」：実装済み（2026-11-02 昼、`kakunin` で確認待ち）。KEYWORDS に stealth・twice・shield・poison・lifesteal・elusive・noattack・regen・doom。状態は `u.revealed`（隠密が解けた）・`u.shieldUsed`・`u.swings`（そのターンの攻撃回数）・`u.doomArmed`。相手が選べる対象は `targetables()` / `canTarget()` を通す。毒・吸収は攻撃と反撃のダメージだけ（効果のダメージには付かない）。装甲で0になったら毒は効かない

- 段階4「条件付き」：実装済み（2026-11-02 昼、`kakunin` で確認待ち）。効果に `cond`（CONDS：hpLE・worldGE・combo・handZero・handGE・maxEGE）と `cn`・`cworld`。`effect()` の最初で `condOK()` を見て、満たさなければその効果だけ発動しない。コンボは `p.played`（そのターンに使ったカードの数。いま使っているカードを含めて2以上）。worldGE はこのキャラ自身も数える

- 段階5「CPU の判断」（2026-11-02 夕）：CPU は1手ごとに盤面を試算して選ぶので、新しい効果もほぼそのまま扱えていた（沈黙は能力持ちに、手札に戻すはトークン以外に、など）。直したのは2つ：登場時以外の効果の価値を、効果の種類と数値から見積もる（`effValue` / `trigValue`）、山札から手札に加える効果は盤面の点数に出ないので少し加点。前の判断と300試合ずつ戦わせて差はなし（悪くはなっていない）。上級は中級に79%、初級に98%勝つ

## 進め方
1. 発動するタイミング → 2. トークンと効果 → 3. 能力 → 4. 条件付き → 5. CPU の判断の調整
- まとまりごとに作って、確認用ブランチ `kakunin` で動画を見せ、オーナーの「OK」で main へ
- CPU は最低限（新しい効果のカードも普通に出せる・対象を選べる・止まらない）を各段階で同時に入れる。賢く使う調整は最後（オーナーも「全部終わってから調整」で同意）
- 各段階で tools/sim（CPU同士の大量対戦）を回して、エラーが出ないことを確かめる
- 1つ足すたびに触る場所：js/shared.js（EFFECTS・KEYWORDS・説明文 cardTextLines）、js/game.js（effect()・戦闘・ターン処理・CPU）、カード工房の入力欄（js/editor.js）、シミュレーター

- 段階6「対象を選べる形と第2弾の仕組み」（2026-11-05）：効果を汎用の `unit`（act＝何をするか・to＝対象）と `player`（act・who）にまとめた。古い種類（dmgTarget など）は `normEffect` → `migrateEffect` で読み込み時に置き換える（全135枚の説明文が前と同じことを確認済み）。対象の役割に `any`（自分か相手のキャラ）と `enemyF`（相手キャラか相手プレイヤー。targets.enemyF に uid か "face"）を追加。新しい効果：`merge`（合体）・`costDown`（このターン／この対戦中、0まで）・`winTimer`（特殊勝利。u.winIn）・act の `unfreeze`／`copy`、grant の「このターンだけ」（u.tmpKws・u.tmpArmor をターン終わりに消す）、タイミング `cardPlay`（自分がカードを使ったとき。pw・pt で世界・種類を絞る）
